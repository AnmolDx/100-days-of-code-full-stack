### What is internet?
Interconnected network of computers around the world.

Server - Device that works 24/7. Clients use this to get data.

IP Address - Unique address of a device. Every device has it.

Whenever searching for something it goes to ISP(Internet Service Provider) then DNS(Domain Name System) it is kind of a address book. It return IP Address to the ISP and ISP send it to Client.

You can look for IP Address on [nslookup](nslookup.io)

When looking/searching/opening a website browser send request to the server(AWS) then in response server send code(html/css/js) to browser and browser compile it and show us the website. This is called request-response cycle.

Server side is called Backend

Client side is called Frontend
