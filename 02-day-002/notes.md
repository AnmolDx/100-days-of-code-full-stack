## Lists

There are two types of lists in html.

1. unordered lists - ul
2. ordered lists - ol

We can change types/bullet points of lists with **type** attribute.

## Anchor Element

it is used to add links to your page.

href = hypertext reference

absolute links - links that we get from internet ex-www.google.com .

relative links - we use file path as link.

## Image Element

It is a single tag. Use to add image to your page.

Same as anchor tag img can either take relative or absolute links

We use alt to show text as alternative if img is either not load or download properly.

We can use height and weight to scale the image but its is not recommended to do this in html

To get line break we use **\<br>**

For Bold - b, Italic - i, Underline - u
