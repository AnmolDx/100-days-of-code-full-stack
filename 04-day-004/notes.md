## Tables in HTML

Tables are used to represent real life table data.

Rows are horizontal

Columns are vertical

Main Row is called table header.

Table's title is written in caption.

## Semantics in Tables

thead - to wrap table header

tbody - to wrap table body

tfoot - to wrap table footer

## Colspan & Rowspan Attributes

It is used to create cells which spans over multiple rows or columns. Its like merge in excel.

## Forms in HTML

Forms are used to collect data from the user.

**Action** Attribute in form - is used to define what action needs to be perfomed when a form is submitted or where the form data should be sent.

## Form Elements

- Input - used to create multiple form controls. There are multiple types of input that can be created using type attribute. You can check a lot of input type on [mdn](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/input)

- Label - Label element represents a caption for an item in a user interface.
