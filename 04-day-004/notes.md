## Tables in HTML

Tables are used to represent real life table data.

Rows are horizontal

Columns are vertical

Main Row is called table header.

Table's title is written in caption.

## Semantics in Tables

thead - to wrap table header

tbody - to wrap table body

tfoot - to wrap table footer

## Colspan & Rowspan Attributes

It is used to create cells which spans over multiple rows or columns. Its like merge in excel.
