# Notes

## Alpha channel

sets the opacity for a color.

range from 0 to 1

rgba(red, green, blue, alpha(0-1))

`#000000a1` last two character is alpha value. 00-ff

## Opacity

Sets the opacity for the element

range from 0 to 1

## Transitions

Transitions enable you to define the transition between two states of an element.

Shorthand - `transition: property name | duration | timing-funtion | delay`
