# Notes

## Using the Console

Console uses REPL - Read Evaluate Print Loop

## Variable

A variable is simply the name of a storage location. It simply reserve the space for values.

## Data Types

- Numbers - positive(7) & negative(-9), Integers(44, -37), Floating(4.5, 6.9)

- NaN - The NaN global property is a value representing Not-A-Number. 0/0, NaN - 1, NaN*NaN. The typeof NaN is number.

- Boolean - represents a truth value either true or false.

- String - text or sequence of characters. anything that is inside quotes.

we can access character of string by `string[indexOfString]`

`string.length` use to get length of string.

- undefined - A variable that has not been assigned a value is of type undefined. Where value is not assigned.

- null - The null value represents the intentional absense of any object value. assign it explicitly

## Operator Precedence

Highest -> Lowest - ( ) | ** | *, /, % | +, -

## Assignment Operators

age = age + 1; age += 1

This can be use with any operators

## Unary Operators

age = age + 1; age +=1; age++ (These all are same). Its called increment operator.

age-- (decrement operator)

Pre-increment(change, then use)

++age

Post-Increment(Use, then change)

age++

## Identifier Rules

All JS variables must be identified with unique names.

- Names can contain letters, digit, underscore, and dollar sign.(no space)

- Name must begin with a letter or $ or _.

- Names are case sensitive.

- Reserved word cannot be use.

- camelCase is generally use in javaScript.
