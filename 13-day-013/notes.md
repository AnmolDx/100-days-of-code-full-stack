# Notes

## Using the Console

Console uses REPL - Read Evaluate Print Loop

## Variable

A variable is simply the name of a storage location. It simply reserve the space for values.

## Data Types

- Numbers - positive(7) & negative(-9), Integers(44, -37), Floating(4.5, 6.9)

- NaN - The NaN global property is a value representing Not-A-Number. 0/0, NaN - 1, NaN*NaN. The typeof NaN is number.

## Operator Precedence

Highest -> Lowest - ( ) | ** | *, /, % | +, -
