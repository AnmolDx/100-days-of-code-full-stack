# Notes

## String Methods

actions that can be performed on objects.

strings are immutable in JS. That means it cannot be change

- `str.trim()` - trims whitespaces from both ends of string & return a new one.

- `toLowerCase()` & `toUpperCase()` - the name says it all.

- `slice()` - returns a part of the original string as a new string.

- `replace()` - seaches a value in the string & returns a nes string with the value replaced.

- `repeat()` - returns a string with the number of copies of a string.

## String method with Arguments

Argument is a some value that we pass to the method.

- `str.indexOf()` - returns the first index of occurrence of some value in string. Or gives -1 if not found.

## Method Chaining

Using one method after another. Order of execution will be left to right.
