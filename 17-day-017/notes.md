# Notes

## Objects Literals

Used to store keyed collections & complex entities. Objects are a collection of properties.

property => (key, value) pair

## Get Values

`object["keyname"]` or `object.keyname`

object converts its key to string even if there is numbers or boolean values.

to change the values we can use `object.keyname = "new value"`. Same will use if we want to add new value.

to delete use `delete object.keyname`.
