## Array Methods

- `forEach(some function definition or name)` - run function/method on each elements in array.

- `map(some function definition or name)` - run function and returns new array.

- `filter(some function definition or name)` - run function and returns new array only if it met the condition(depend upon filter definition).

- `every(some function definition or name)` - returns true if every element of array gives true for some function. Else returns false.

- `reduce(reducer function with 2 variable for (accmulator, element))` - reduces the array to a single value.
